# Real-Time Chat — Client

Next.js client for a room-based real-time chat. Pick a username and a room, then exchange messages instantly with everyone in that room. Server: [socket-io-real-time-chat-server](https://github.com/halilenesozdemir/socket-io-real-time-chat-server).

## Run locally

Start the server first (port 5000), then:

```bash
npm install
npm run dev
```

Open http://localhost:3000 in two browser windows, join the same room with different usernames, and chat.

## Stack

Next.js 14 · React · Socket.IO Client · Tailwind CSS
